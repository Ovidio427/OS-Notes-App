# 📝 Note Taking App

A modern, responsive note-taking application built with Next.js and Firebase. Easily create, edit, organize, and manage your notes in one place. The application provides a simple and intuitive interface for keeping track of your thoughts, ideas, and important information.

# Live Demo

[🌐 View Live Site](https://osmnotez.netlify.app/)

# ✨ Features

Create Notes – Quickly create and save new notes.
Edit Notes – Update your notes whenever you need to.
Delete Notes – Remove notes you no longer need.
Real-time Database – Store and synchronize notes using Firebase Firestore.
Authentication – Secure user authentication with Firebase Authentication.
Responsive Design – Works across desktop, tablet, and mobile devices.
User-specific Notes – Keep each user's notes private and organized.
Modern UI – Clean and user-friendly interface.

# 🛠️ Tech Stack

* Technology	Purpose
* Next.js	React framework
* React	User interface
* Firebase	Backend services
* Firebase Authentication	User authentication
* Cloud Firestore	Database
* Tailwind CSS	Styling
* JavaScript / TypeScript	Application logic
